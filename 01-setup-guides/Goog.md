## Introduction

  

Want unlimited Google Photos storage? This guide will help you set up the Nox emulator with Magisk Delta, LSPosed, and Pixelify GPhotos. Follow these simple steps to spoof your device and enjoy free storage.

  

---

  

## 1. Nox Emulator Setup (Android 9)

  

{{< callout type="tip" title="Important" >}}

Always create a new Nox instance for each Gmail account. Do not copy old instances.

{{< /callout >}}

  

- Enable Root in Nox settings.

- Set your preferred language.

- Enable Direct Mode, Speed Mode, or Basic Mode (DirectX).

  

---

  

## 2. Launch the Emulator

  

- Open your configured Nox instance.

- Install **Magisk Delta** and **LSPosed (App)**.

  

---

  

## 3. Configure Magisk Delta

  

- Open Magisk Delta.

- Tap **Install**.

- Select **Direct install into system partition**.

  

---

  

## 4. Disable Root in Nox

  

- Uncheck the Root option in Nox settings.

- Reboot the emulator.

  

---

  

## 5. Enable Zygisk

  

- Open Magisk Delta settings.

- Enable **Zygisk**.

  

---

  

## 6. Transfer LSPosed Zip

  

- Drag and drop the LSPosed ZIP file into the emulator.

  

---

  

## 7. Install LSPosed Module

  

1. Open Magisk Delta.

2. Go to the **Modules** section.

3. Tap **Install from device**.

4. Go to `Files > Pictures` and select the LSPosed ZIP file.

5. After installation, reboot the emulator.

  

---

  

## 8. Verify LSPosed Installation

  

- Open Magisk Delta.

- In the **Modules** tab, check if **zygisk - LSPosed** is listed and enabled.

  

---

  

## 9. Install Pixelify-GPhotos

  

- Install the **Pixelify-GPhotos** app on your emulator.

  

---

  

## 10. Set Up Google Photos

  

1. Sign in to Google Play Store.

2. Install the **Google Photos** app.

  

---

  

## 11. Activate Pixelify GPhotos Module

  

1. Open the LSPosed app.

2. Go to **Modules** and select **Pixelify GPhotos**.

3. Enable the module.

4. Tick all module checkboxes.

5. Reboot the emulator.

  

---

  

## 12. Configure Pixelify GPhotos

  

1. Open the Pixelify GPhotos app.

2. Choose **Device to Spoof** (Recommended: Pixel XL).

3. Tap **Force Stop Google Photos**.

4. Tap the **(Redirection)** button.

  

---

  

## Troubleshooting: Uncertified Device Error

  

{{< callout type="warning" title="If you see 'Device is not certified' in Play Store" >}}

1. **Install "Device ID" App**

- Open the app and copy the **Google Service Framework (GSF)** number.

2. **Register GSF ID**

- Paste the copied GSF ID on the required website and register it.

3. **Clear Google App Data**

- Go to Android Settings.

- Clear data for all Google apps.

- Reboot the emulator.

{{< /callout >}}
